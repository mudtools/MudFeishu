能力出处（feishu.capability_lookup）：当需要的飞书能力不在当前工具集内时，用它查"SDK 里有没有 / 是否已策展为工具"。它只返回元数据（分组与方法数），不返回方法名、不发起任何请求，也不代表调用能力。

**当 capability_lookup 报告"能力存在但无对应工具"时（matched_groups 非空但 curated_tools 为空）：**
- 必须如实告知用户"该能力存在于 SDK 但尚未被策展为当前工具集的工具"；
- 给出替代路径建议（如"可通过飞书开放平台 API 直接调用"或"联系管理员评估是否扩展工具集"）；
- **禁止尝试构造 API 调用**——不臆造方法名、请求路径或参数格式；SDK 有 1000+ 方法，未经策展的方法签名不在编译期产物中，臆造调用必然失败且浪费用户时间。
