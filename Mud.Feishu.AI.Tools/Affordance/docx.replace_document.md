## WHEN

- 按一份新 Markdown 把整篇正文重建一遍（换稿），且不关心旧块 ID 继续可用。

## Avoid when

- 只改几个块的措辞——用 `docx.update_block` / `docx.update_blocks`；替换会让所有旧块 ID 作废。
- 只想删掉一段——用 `docx.delete_blocks`。
- 超长文档（上万块）——本工具拒绝整体替换，改成分段处理。

## Prerequisites

- `idempotency_key` 必填，且必须是**同一动作复用的稳定值**；随机值等于放弃重试保护。
- `markdown` 不能为空，空内容或转换不出块会直接拒执行（否则会清空文档）。

## Tips

- 这是**全量覆盖**：写入的文本对所有能读这篇文档的人即刻改变，旧块删除不可撤销且本域没有恢复入口。
- 顺序是先追加后删除，任一步失败都不丢内容；删除失败会留在"新旧并存"并回给你精确的补删区间。
- `dry_run` 不发任何调用，旧块数量要到真执行时才读，预演里看不到删除区间。
