## WHEN

- 按一份新 Markdown 把整篇正文重建一遍（换稿、批量修订、从模板重建），且不关心旧块 ID 继续可用。
- 远端内容已不可信，需要以本地版本为准整体覆盖。

## Avoid when

- 只改几个块的措辞——用 `docx.update_blocks`（单块即 1 元素数组）；替换会让所有旧块 ID 作废。
- 只改一小段且要防误改——用 `markdown.patch`，它靠原文匹配定位。
- 只想删掉一段——用 `docx.delete_blocks`。
- 文档里有必须保留的评论或非正文结构——重建会替换正文块，先确认这些不随块丢失。
- 对象不是新版文档——本工具只作用于 docx。
- 超长文档（上万块）——本工具拒绝整体替换，改成分段处理。

## Prerequisites

- `document_token`（doxcn…）+ 非空 `markdown`；空内容或转换不出块会直接拒执行（否则会清空文档）。
- 需 docx:document；写工具默认不启用，启用前须宿主授权。
- `idempotency_key` 可选但**强烈建议**：重试要复用同一值（必须是同一动作复用的稳定值，随机值等于放弃重试保护），否则可能重复插入。

## Tips

- 这是**全量覆盖**：写入的文本对所有能读这篇文档的人即刻改变，旧块删除不可撤销且本域没有恢复入口。
- 先 `dry_run=true` 看步骤，再真写；预演不发任何调用，旧块数量要到真执行时才读，所以预演里看不到删除区间。
- 顺序是先追加后删除，任一步失败都不丢内容；删除失败会留在"新旧并存"并回给你 `partial_failure=true` 与精确的补删区间——按指引清理旧块，不要盲目重跑整篇。
