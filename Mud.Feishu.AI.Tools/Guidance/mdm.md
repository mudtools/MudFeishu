
# 主数据 · 国家/地区（mdm.*）

## 路由优先级（先判断对象属于哪个域）
- **国家 / 地区 / ISO 代码 / 国际区号 / 大洲** → `mdm.*`；**时区换算、日期本地化**不属于本域，
  没有对应工具时先用 `feishu.capability_lookup` 确认「是不存在还是没启用」，不要臆造调用。
- 只有拿到 **`MDCT` 编码**（形如 `MDCT00000001`）时才用 `mdm.get_countries`；
  只拿到中文/英文国名而没有编码时，本域没有"按名字搜编码"的工具，应先向用户索取编码，
  或说明"编码需从主数据/上游系统取得"——不要反复用不同编码试错。

## 前置链
（有编码）`mdm.get_countries` 一次批量查（最多 100 个）→ 直接用返回的 `name` / `full_name` / `alpha_2_code` 回答。
（无编码）先向用户/上游系统索取 `MDCT` 编码；本域不提供"按名称反查编码"的通道。

## 降级策略
- 返回 `found=false`（`total=0`）表示**编码不存在或字段/语言取值不被支持**：
  核对编码格式（`MDCT` + 8 位数字）与 `fields` / `languages` 取值后重试一次；
  仍为空则如实告知用户"该编码查不到"，不要换编码连续重试。
- 工具报"未注册客户端（软缺席）"表示**宿主未启用 MDM API**：如实告知用户该能力当前不可用，
  不要改用其它域工具去"拼"一个近似答案。

## 避坑
- **`fields` 决定回填哪些事实**：只点需要的字段（如 `["name","alpha_2_code"]`）——要回传用不到的字段
  只会挤占上下文；`fields` 与 `languages` 都是必填，不能省略。
- **`languages` 的顺序有意义**：`name` / `full_name` 取其中**排序第一**的语言；
  要中文回答就把 `zh-CN` 放第一位，要英文就用 `en-US`。
- **批量上限 100**：超过会在本地被拒绝（不会消耗一次下游调用），请分批。
- 本域返回的是**主数据事实**，不是业务数据；不要把它当作"用户所在地区"的证据——
  那需要通讯录/考勤域的授权数据（且属 PII，需宿主显式启用）。

## 安全规则
- 本域为**只读**（无写操作、无 `dry_run` 语义）；调用仍受 scope 审计约束（需 `mdm:country_region:read`）。
- 国家/地区是**公共参考数据**（不含员工个人信息），故不属于 PII 工具；但仍不得据此推断或披露
  任何用户的个人信息。
- 只使用本域真实工具名（`mdm.get_countries`），不臆造不存在的工具或 API。

## 示例
- 「`MDCT00000001` 是哪个国家？」→ `mdm.get_countries(ids=["MDCT00000001"], fields=["name","alpha_2_code"], languages=["zh-CN"])
  → 用返回的 `name` 回答。
- 「把这批地区编码换成英文名」→ `mdm.get_countries(ids=[...最多 100 个...], fields=["name"], languages=["en-US"])`。
- 用户只给了"安道尔"没给编码 → 说明"本域按 MDCT 编码查询，请提供编码"，不要猜编码。
