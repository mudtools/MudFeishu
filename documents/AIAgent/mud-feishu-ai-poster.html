人工确认管线
写工具由 MAF 审批管线在调用前拦截，先经宿主批准再执行。 批准状态单一所有权，SDK 不签发任何凭据，模型无法自批复；未授权一律 fail-closed。
多租户隔离
appKey 作用域切换 + 用户令牌 AsyncLocal 隔离，令牌全生命周期托管。 跨租户召回即数据泄露，禁止默认租户兜底。
MCP 服务器
独立可选包，stdio JSON-RPC 2.0。进程外 Agent（Claude Code / Cursor / 自建 harness） 即插即用，白名单同源、执行链零旁路。
知识检索 RAG
Aily 托管知识问答（零基础设施）与自建向量检索双面并存： 结构优先切片 → 向量召回 → 语料索引，按租户隔离。
