# Mud.Feishu 代码注释规范

> **定位**：normative（规范性）文档。本文件是 Mud.Feishu 源码注释的**唯一权威写作标准**。
> **适用范围**：8 个交付项目的**手写** `.cs` 源码注释（`Mud.Feishu.Abstractions` / `Mud.Feishu` / `Mud.Feishu.WebSocket` / `Mud.Feishu.Webhook` / `Mud.Feishu.Redis` / `Mud.Feishu.Authentication` / `Mud.Feishu.EventCallback` / `Mud.Feishu.OpenTelemetry`）。
> **不适用**：生成器产物（`Mud.Feishu.DataModels/`、`EventCallback` 生成事件类型、`Mud.Feishu/Interfaces/**` 中生成器发射的实现类）——其注释由生成器模板控制；`Demos/`、`Tests/`（见 §8.4）。
> **执行方式**：`pwsh ./scripts/audit-comments.ps1 -Strict`（CI 门禁，见 §7）。

---

## 0. 一句话

**源码注释只承载两件事：对外契约（消费者需要的语义）与不可从代码推断的约束（锁序、幂等、顺序依赖、AOT 抑制理由、安全语义）。决策史一律不进源码。**

## 1. 三条判据（写注释前自问）

| # | 问题 | 若"是" |
| --- | --- | --- |
| 1 | 这条信息**消费者**需要吗？ | 写入 **L1**：只答契约——做什么、边界、异常、线程安全、幂等、副作用 |
| 2 | 这条信息**维护者**需要、且**从代码读不出来**吗？ | 写入 **L2**：只答约束——锁序、不变式、顺序依赖、AOT/性能禁用、安全语义 |
| 3 | 这条信息是"**我们以前怎么错的 / 上游第几版改了什么**"吗？ | **不许写在源码里** → 写入 `documents/决策档案/`（**L3**） |

**自检**：删掉这条注释，维护者会不会踩坑？回答"不会"即应删除。

### 1.1 分层模型

| 层 | 名称 | 载体 | 内容边界 | 上限 | 处置 |
| --- | --- | --- | --- | --- | --- |
| **L0** | 版权头 | 文件头 6 行 `//` | 由 `.editorconfig` 的 `file_header_template` 生成 | 6 行 | 不动 |
| **L1** | API 契约 | public/protected 成员的 `/// <summary>/<param>/<returns>/<exception>` | 契约、边界、异常、线程安全、幂等、副作用、示例 | `<remarks>` ≤ 6 行 | 保留/压缩 |
| **L2** | 实现约束 | `//` 注释；或 internal/private 成员的 `///` | 不可从代码推断的约束 | 单块 ≤ 4 行 | 压缩保留 |
| **L3** | 决策史 | `documents/决策档案/`（**不在源码**） | 版本适配、缺陷复盘、验收记录、报告引用 | 不适用 | 转移 |
| **L4** | 迁移指引 | `[Obsolete]` 消息（模板）+ `documents/决策档案/迁移与弃用史.md` | "改用 X + 一句理由 + 移除版本" | 消息 ≤ 80 字 | 模板化 |

> `/// <remarks>` 会**进入 NuGet 包与 IDE IntelliSense**，是**对外文档面**——被施工过程污染属对外文档缺陷，不只是风格问题。

## 2. 硬性规则（R 系列，机器可校验）

| 编号 | 规则 | 校验 |
| --- | --- | --- |
| **R-01** | **内部编号禁入源码**。以下编号族**不得**出现在任何 `///` 或 `//` 注释中：`BC-`、`U-`、`C-`、`F-`、`SW-`、`TMA`/`TMA2-`、`TMF`/`TMF2-`、`TMR`/`TMR2-`、`WHF-`、`WS-`/`WS2-`、`R-E`、`ARC-`、`AOT-`、`NEW-`、`S-`、`A-`、`M-`、`R-`、`X`、`D\d\d`、`I\d\d`、`P2-`/`P3-`、`Phase-A/B/P`、`Batch 1/2/3` | 脚本 |
| **R-02** | **禁止修复史叙述**。"修复前/改造前/原实现/原先/不再误判/本仓/以前/曾经"等对比句式不得出现 | 脚本 |
| **R-03** | **`<remarks>` ≤ 6 行**（含标签行）；单个成员至多 1 个 `<remarks>`；超出内容按 §1 重派。**适用范围**：仅 **public/protected** —— 只有它们进入 NuGet 包与 IDE IntelliSense；**internal/private** 承载的 `<remarks>` 不对外发布，保持契约完整即可，不追 6 行上限 | 脚本（W 级） |
| **R-04** | **禁止硬编码仓库内部文档路径**：`.docs/…`、`documents/…`、`AGENTS.md`、`CHANGELOG`、`验证报告`。**允许**飞书官方 OpenAPI URL（业务契约） | 脚本 |
| **R-05** | **交叉引用收敛**：同一段样板注释在 ≥3 个成员/文件中重复时，收敛为**一次**类型级 `<seealso>` 或集中到单一主题页，成员内只留必要语义 | 脚本（W 级）+ 人工 |
| **R-06** | **禁止装饰噪音**：`// ─────`、`// ====`、`// ↓↓↓` 等分节线/ASCII 框；`catch { /* … */ }` 式空体括号注释；"以下三个成员…"式占位说明 | 脚本 |
| **R-07** | **`[Obsolete]` 消息用模板**（§4），≤ 80 字 | 脚本 + 人工 |
| **R-08** | **强词纪律**：`禁止/必须/不得/务必/故意/刻意` 仅用于**真实约束**；同一约束在同一文件内不得重复表述 | 人工 + 附录 A 白名单 |
| **R-09** | **术语表约束**（§5）：允许使用领域口语词，但语义须落在术语表定义内 | 人工 |
| **R-10** | **排版**：中文注释用全角标点；中英文之间加空格；标识符一律 `<c>` 包裹；单行 ≤ 120 字符 | 人工 / `dotnet format` |
| **R-11** | **`<remarks>` 只写"当下为什么这样"**，不写"曾经发生过什么"（时间轴信息属 L3） | 人工 |
| **R-12** | **豁免必须显式**：确需保留的例外，在**同行或上一行**写 `// comment-allow: <原因>`（原因必填） | 脚本强制 |

### 2.1 唯一例外：`[Obsolete]` 消息可含上游编号

`[Obsolete]` 消息是消费者**在编译期**看到的唯一上游溯源入口，因此**允许**出现**上游**编号（如 `BC-30`）。
**不允许**出现本仓内部分支编号（`TMA-17`、`WHF-07`、`P2-13` …）——它们对消费者无意义。

## 3. 正反例

### 3.1 A 类（上游适配史）→ 转移

**反例**：

```csharp
/// <b>Mud.HttpUtils 3.0.0 适配（上游 BC-27）</b>：上游 <c>IAppContextSwitcher</c> 已移除
/// <c>UseApp(string)</c> / <c>UseDefaultApp()</c> / <c>BeginScope(string)</c> 三个成员，
/// 生成器也不再默认发射它们。本接口<b>显式重声明</b>这三个成员以保持契约不变 …
```

**正例**（语义不丢，历史转 `documents/决策档案/上游契约适配史.md`）：

```csharp
/// <remarks>
/// 本接口显式重声明三个无作用域切换成员，以维持 <c>Mud.Feishu</c> 的对外契约与生成实现类的兼容性：
/// 签名必须与上游 <c>IAppContextSwitcher</c> 原签名逐字一致，否则生成器不再豁免、实现类将落入契约补全。
/// 新代码应改用 <see cref="IAppScopeSwitcher.UseAppScope(string)"/>（守卫相同，且释放时自动归还上下文）。
/// </remarks>
```

### 3.2 C 类（缺陷复盘）→ 保留约束、剥离历史

| 原注释（禁止） | 改后（允许） |
| --- | --- |
| `/// S-2 修复：原实现固定取 endpoints[0]，集群/主从场景下该节点不可用时无故障转移。` | `// 必须遍历全部可用主节点：单取 endpoints[0] 在集群/主从下无故障转移。` |
| `/// P2-2 修复（WS2-07 / I12）：原实现为 _connectionState == 1 && …` | 删除（属实现细节，无不可推断约束） |
| `// 改造前顺序是「Cancel → CloseAsync → 占位」…` | `// 顺序约束：必须先占位再 CloseAsync，否则关闭握手把状态推回……` |
| `/// TMA2-09 / D13：热更新改为「Phase-P 锁外预清库 + 两阶段事务化」（TMF-02）` | `// 清库是 IO（Redis SCAN + 逐键 DELETE），禁止在锁内执行。` |

### 3.3 F 类（内部文档路径）→ 收敛

**反例**（该 4 行样板在 15 个文件 / 18 处逐字复制）：

```csharp
/// 此时本方法会把错误 JSON 当作文件内容返回。落盘前应按 <c>Content-Type</c> 自检，详见 <c>documents/ErrorHandling.md</c>。
```

**正例**（语义留在成员内，跨成员重复的部分由**类型级 `<seealso>` 一次**承担）：

```csharp
/// 落盘前须按 <c>Content-Type</c> 自检：飞书部分业务错误以 HTTP 200 + JSON 错误体返回，此时响应体会被当作文件内容。
```

### 3.4 D 类（真实约束）→ 保留，仅去编号

```csharp
// 原：锁序固定为 _configApplyLock → _lazyRebuildLock / _registryLock / _defaultAppLock，禁止反向获取。
```

## 5. 术语表（允许保留的领域口语词）

| 词 | 定义 |
| --- | --- |
| 兜底 / fallback | 主路径不可用时的替代路径 |
| 打门 / 门（PurgeGate） | 令牌恢复的短路门机制，命中时拒绝从 store 恢复凭据 |
| 短路 | 提前返回而不执行后续步骤 |
| fail-open / fail-closed | 失败时放行 / 失败时拒绝 |
| 幂等 | 重复执行与单次执行结果等价 |
| 回归 | 已修复缺陷重新出现（测试名中的 `*RegressionTests` 沿用） |
| 收口 | 多处分散实现收敛到单一出口 |

## 6. 豁免机制（R-12）

```csharp
// comment-allow: <必填原因>
// BC-30 是上游 CHANGELOG 的锚点，此处作为消费者唯一的溯源入口保留。
```

- 标记写在**命中行的同行或上一行**。
- **只允许逐行豁免**，禁止整文件豁免（整文件豁免会让该文件后续所有新命中静默通过——这正是 `scripts/audit-config-keys.ps1` 在 R5 重构中修掉的缺陷）。
- 原因必须能让复核者判断"为什么它不是过程叙述"。

## 7. 门禁与执行

```bash
pwsh ./scripts/audit-comments.ps1              # 报告模式（恒 exit 0，打印统计与新增命中）
pwsh ./scripts/audit-comments.ps1 -Strict      # 门禁模式（新增命中 ⇒ exit 1）
pwsh ./scripts/audit-comments.ps1 -ListAll     # 打印全部命中（含匹配标记）
```

- **接入点**：`scripts/verify-build.ps1` 步骤 1.5 与 `.github/workflows/dotnet-publish.yml`。
- **存量治理模型**：**存量冻结、新增零容忍**。历史命中登记在 `scripts/comment-baseline.txt`（按**内容哈希**冻结，故重排版/行号漂移不会使基线失效），**只减不增**——`-UpdateBaseline` 在基线变大时以 exit 2 拒绝（除非显式 `-Force`）。
- **每个里程碑必须删除它修好的基线条目**，门禁随即证明"真的改干净了"。M4 目标：基线**零条目**。
- **扫描范围**：8 个交付项目；排除 `Demos/`、`Tests/`、`bin/`、`obj/`、`*.g.cs`、`*.Designer.cs`、`GlobalUsings.cs` 与 `Mud.Feishu.DataModels/`（生成产物，`-IncludeDataModels` 可临时启用）。
- 本规范文档本身含禁用词示例，但门禁**只扫描 `.cs`**，不会自触发。

## 8. 配套

### 8.1 决策史去哪

`documents/决策档案/`（**受版本控制**）。索引见其 `README.md`，编号全集见 `编号索引.md`。

### 8.2 新建文件时

从文件头 6 行版权块开始（由 `dotnet format` 与 `.editorconfig` 维护），随后是 `namespace`；**不要在文件级写"本文件用于…"的过程说明**（属 L3）。

### 8.3 删除注释前

先确认它不是附录 A 的**必须保留约束**；先归档（`documents/决策档案/`）**后**精简。

### 8.4 `Tests/` 与 `Demos/`

- `Tests/`：**测试方法名中的编号保留**（它们是回归溯源锚点），但**注释正文**不得再写过程叙述。
- `Demos/`：消费已发布包，注释冻结，不整改。
