# 决策档案（L3）

本目录是 **L3 决策史**的唯一载体：**上游版本适配史、缺陷复盘、验收记录、被精简掉的注释理由**。
这些内容**不得**写在源码注释里（见 `documents/代码注释规范.md` §1 与 R-01/R-02/R-11）。

## 何时写入本目录

源码注释精简时**先归档、后删除**（规范 §8.3）。具体包括：

| 被移出源码的信息 | 落点 |
| --- | --- |
| 上游契约变更导致的适配理由（曾经的写法、为何必须保持签名逐字一致） | `上游契约适配史.md` |
| `[Obsolete]` 成员的完整迁移史（何时弃用、替代者、移除版本） | `迁移与弃用史.md` |
| 内部编号的含义反查（`BC-*`、`U-*`、`C-*`、`TMA*`、`WHF-*`、`P0-*` 等） | `编号索引.md` |
| 类型级长约束被压缩后剩下的论证（"为什么不用另一个方案"） | `注释精简归档.md` |

## 编号索引

源码中**禁止**出现内部编号（R-01）。若确需保留例外，必须用同行或上一行的
`// comment-allow: <原因>` 显式豁免（R-12），且原因须能让复核者判断其非过程叙述。

编号到含义的映射统一记在 `编号索引.md`；需要理解某个历史编号时**查表**，不要在源码里找回。
